# source/_posts —— 文章根目录

> 全部文章都在这里，按 **`年份/分类/文件名.md`** 两级归档。

## 说明

### 当前归档结构

```

├── 2023/            2 篇   早期文章，未分类

├── 2025/            7 篇   学习类 / 阶段总结
└── 2026/            6 篇   STM32N6 / 生活
```

### 写作约定

1. **文件名 = 文章标题**（可直接用中文）。`_config.yml` 开启了 `permalink_pinyin`，
   构建时会把标题转成拼音再拼进链接，所以 URL 不会出现中文。
2. **图片**：`post_asset_folder: true`，每篇文章会有一个**同名目录**存放配图，正文用相对路径引用，例如
   `![接线图](接线图.png)`。
3. **front-matter** 必填 `title` / `date` / `category`，`tags` 可选（数组）。

### 关于「同名图片目录」

- 这些目录（如 `2026/STM32N6/02_STM32N6开发实战1/`）是 Hexo 的**资源目录**，只放图片等素材。
- **不要在图片目录里放 `README.md`**：`_posts` 下的 `.md` 会被当成文章渲染，会污染站点。
  图片目录的说明已经写在本文件与各分类的清单里。

### 注意

- 以 `_` 或 `.` 开头的文件/目录会被 Hexo 忽略（本站正是利用这一点存放 `_README.md`）。
- 增删文章后记得运行 `npm run manifest` 刷新清单与文章索引。
