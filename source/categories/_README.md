# categories —— 分类聚合页

> 汇总全站分类，点击进入 `/categories/分类名/`。

## 说明

- 文件：`index.md`，`layout: categories`（同样不能用 `page`）。
- 分类来源：文章 front-matter 的 `category` 字段。当前实际存在两个分类：**学习记录**、**我的生活**。
- 文章**归档目录**（`_posts/2024/学习类/`）与**分类字段**（`category: 学习记录`）是两套体系：
  目录决定文件放哪，`category` 决定站点分类页怎么归组。新增文章时两者都要照顾到。
