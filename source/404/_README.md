## 说明

- 文件：`index.md`，`layout: page`，构建产物是站点根目录下的 `404.html`（GitHub Pages 会自动识别）。

- 注意页面里不要写绝对路径 `/404/`，用相对站点的 `url_for('/')` 形式更稳妥。
