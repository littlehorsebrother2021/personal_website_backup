# 评论区与封面/背景配置

## 1. 评论区

主题已经内置 Gitalk、Gitment、Disqus、Livere、Valine、Waline、Twikoo 等评论系统。
评论卡片是一个“接口”：在 `themes/hexo-theme-matery/_config.yml` 中启用哪一套，
留言板页和文章页就会自动渲染对应的评论卡片。目前接口已保留，但没有启用任何后端，
所以页面暂时不显示评论框，也不会加载无效脚本。

推荐优先使用 Twikoo 或 Waline：

### Twikoo（推荐，免费额度即可）
1. 按官方文档 https://twikoo.js.org 部署到腾讯云 CloudBase，获得环境 ID（如 `xxx-xxxxx`）。
2. 编辑 `themes/hexo-theme-matery/_config.yml`：
   ```yaml
   twikoo:
     enable: true
     envId: 你的环境ID
   ```
3. 重新生成：`hexo clean && hexo g`。

### Waline
1. 按官方文档 https://waline.js.org 部署服务端（Vercel、自建均可），获得服务地址。
2. 编辑 `themes/hexo-theme-matery/_config.yml`：
   ```yaml
   waline:
     enable: true
     serverURL: https://你的服务地址
   ```
3. 重新生成：`hexo clean && hexo g`。

### Valine（需要 LeanCloud）
在 `themes/hexo-theme-matery/_config.yml` 中填写 `valine.appId`、`appKey`、`serverURLs`
并设置 `enable: true`。该选项同时会开启留言板页的“弹幕”功能。

> 注意：三个方案只能启用一个，避免页面同时出现多个评论框。

## 2. 封面与背景图

### 站点背景（banner）
主题按星期读取 `themes/hexo-theme-matery/source/medias/banner/0.jpg` 到 `6.jpg`
（0 是周日，6 是周六）。想换背景，直接替换这 7 张图片即可。

### 文章默认封面（featureimages）
首页卡片、文章头图、归档/分类/标签页在文章没有指定图片时，会从
`theme.featureImages` 列表中按文章标题哈希取一张，因此目前的图“看起来总是那几张”。
有两种美化方式：

#### 方式一：一键批量更新（推荐）
把图片按喜欢的顺序放进两个文件夹（只支持 jpg/jpeg，脚本会自动改名为
`0.jpg`、`1.jpg`...），然后运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\update-covers.ps1 `
    -FeatureFolder .\assets\feature -BannerFolder .\assets\banner -Build
```

- `-BannerFolder`：7 张站点背景图（可选）。
- `-FeatureFolder`：新的文章默认封面图，数量不限（可选）。
- `-Build`：自动执行 `hexo clean && hexo generate`。

脚本会同步更新 `themes/hexo-theme-matery/_config.yml` 中的 `featureImages` 列表，
保证随机背景逻辑和列表一致。

脚本默认会把新图片**居中裁剪并缩放**为统一尺寸，避免页面出现黑边：
banner 输出 `1280x720`，文章封面输出 `640x426`。可以用
`-BannerWidth/-BannerHeight/-FeatureWidth/-FeatureHeight` 修改目标尺寸；
如果不想缩放，加 `-NoResize` 参数原样拷贝。

#### 方式二：单篇文章自定义封面
在文章 front matter 中添加：

```yaml
img: /medias/my-cover.jpg      # 首页卡片和文章头图
cover: true                    # 加入首页顶部轮播（可选）
coverImg: /medias/other.jpg    # 单独指定轮播图（可选）
```

图片文件放到 `themes/hexo-theme-matery/source/medias/` 下即可，引用路径以 `/medias/...` 开头。

### 注意事项
- 图片体积建议控制在几百 KB 内，先在本地压缩再放进去，否则首页和文章页会变慢。
- 改完图片或配置后，必须 `hexo clean && hexo generate` 再部署，旧文件不会自动消失。
