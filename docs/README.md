# docs —— 专题文档

> 存放**长文档 / 操作手册**。和项目根的 `README.md`（总览）分工不同：这里是一篇篇可以独立阅读的教程。

## 说明

| 文档 | 内容 |
| :--- | :--- |
| `评论区与封面配置.md` | ① 评论系统选型与启用步骤（Twikoo / Waline / Valine）；② 站点背景图与文章默认封面的更换流程 |

### 文档分工

| 文件 | 定位 | 读者 |
| :--- | :--- | :--- |
| 根 `README.md` | 项目总览、命令速查、目录地图 | 刚接手项目的自己 |
| 根 `MANIFEST.md` | 全站文件清单、目录索引、文章索引（自动生成） | 想找某个文件时 |
| 根 `GIT-GUIDE.md` | Git 命令速查、撤销回退、多电脑同步 | 忘了 git 怎么用时 |
| `docs/*.md` | 专题操作手册 | 要配置某个具体功能时 |
| 各目录的 `README.md` / `_README.md` | 该目录放什么、怎么命名 | 在某个目录里工作时 |

### 新增一篇专题文档

1. 在 `docs/` 下新建 `某个主题.md`，第一行写 `# 标题`。
2. 在本文件的「说明」表格里加一行，说明它解决什么问题。
3. 执行 `npm run manifest` 刷新清单。

### 注意

- `docs/` 不在 `source/` 下，**不会被 Hexo 发布**，可以放心写内部笔记。
- 这里的文档不会被自动编号，靠文件名和本表格检索；主题名称请用中文，便于搜索。
